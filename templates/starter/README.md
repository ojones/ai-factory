# Starter Template

This is the Factory's **Starter Template** (see root
[GLOSSARY.md](../../GLOSSARY.md)): the fixed scaffold every new Built
Application is seeded from at the start of a Build Run — directory
structure, Dockerfile, and boilerplate, kept structurally identical across
Built Applications per [STANDARDS-CODING.md](../../STANDARDS-CODING.md).

**This directory is not meant to be run standalone as a product.** It's a
template: copy/seed it into a new Built Application's own repo, then build
the actual application on top of it. The example route and component here
(`/api/health`, the `App` component) exist only to prove the scaffold's
shape works end to end — they are intentionally trivial.

See [AGENTS.md](AGENTS.md) in this directory for how to run, build, and
test it, and for pointers back to the full Standards.
